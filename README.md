## ✨ Features

### 🎯 **Smart Problem Generation**
- **Base number selection**: Practice specific number families (1s, 2s, 3s... up to 12s)
- **Multiple operations**: Addition, subtraction, multiplication, and division
- **Hard problems only**: Exclude easy numbers (0, 1, 2, 5, 10) for advanced practice
- **Double digit operands**: Include numbers up to 99 for grade 4-5 students
- **No repeat problems**: Generate completely unique worksheets

### 📄 **Perfect Print Layout**
- **Guaranteed 100 problems per page**: Exactly 10 rows × 10 columns
- **Clean page breaks**: No problems split across pages
- **Traditional vertical format**: Familiar math worksheet appearance
- **Print-optimized spacing**: Professional classroom-ready output

### 🎨 **Flexible Customization**
- **Multiple pages**: Generate 1, 2, 3+ pages as needed
- **Select All option**: Quickly choose all base numbers
- **Mix and match**: Combine different operations and difficulty levels
- **Instant preview**: See your worksheet before printing

## 🚀 Quick Start

1. **Visit [mathfor.fun](https://mathfor.fun)** - No downloads required!
2. **Select your options**:
   - Choose base numbers to practice (e.g., 7s and 9s)
   - Pick operations (addition, multiplication, etc.)
   - Set difficulty level and page count
3. **Click "Generate Worksheet"**
4. **Print and practice!**
